# Diario Forza

App per il telefono di Samuele Riccio per seguire la scheda del 06/12/2026 (1ª fase di aumento carichi, ondulata settimanale: 5 giorni per 6 settimane): serie, pesi, recuperi, progressi, peso e girovita. I record della scheda del 13/05/2023 restano come punto di partenza nei grafici.

Si installa da Safari con Condividi → Aggiungi alla schermata Home e funziona anche senza connessione. I dati degli allenamenti restano solo sul telefono: per non perderli usa Esporta backup in Progressi → Storico.
